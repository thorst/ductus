# `ductus init`

Start a new project: settings, environments, resources and a first interface, ready for `ductus test`. The folder must be empty (a fresh Git clone is fine).

```text
ductus init [OPTIONS] [DIR]
```

**Arguments**

| | What it does | Default | Environment |
|---|---|---|---|
| `<DIR>` | The folder to make the project in (made if missing). | `.` |  |
