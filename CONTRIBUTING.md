# Contributing

Thanks for your interest. The project is in early development; issues and discussions are welcome.

## Sign your commits (DCO)

We use the [Developer Certificate of Origin](https://developercertificate.org/) instead of a CLA. Add a sign-off line to each commit:

```
git commit -s -m "Your message"
```

This adds `Signed-off-by: Your Name <you@example.com>`, certifying that you have the right to submit the work under the project's Apache-2.0 license.
